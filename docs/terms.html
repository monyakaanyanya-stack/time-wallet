1. 本アプリについて

本アプリは、SNSの使用時間を可視化し、自分で決めたSNS予算の中で使い方を整えながら、記録した自分の時間や写真を残して振り返るためのアプリです。SNS利用を完全に禁止するものではなく、記録中や予算を超えたときに対象のSNSアプリをブロックする場合があります。データは原則として端末内に保存され、開発者の独自サーバーへ日々の記録を送信することはありません。バックアップ機能を利用する場合は、あなた自身のiCloud（AppleのCloudKit）を利用し、Appleの規約・仕様が適用されます。

2. サブスクリプション

本アプリの全機能は、サブスクリプション契約またはトライアル期間中にご利用いただけます。料金プランは次のとおりです。

  • 年額プラン：5,980円／年（14日間の無料トライアル付き）
  • 月額プラン：880円／月（無料トライアルなし）

年額・月額で機能差はありません。違いは支払い期間・割引・年額のみの無料トライアルの3点です。価格は予告なく変更される場合があり、最新の価格は購入画面（App Store）に表示されるものが適用されます。表示通貨はお使いのApp Storeの地域に従います。

3. 無料トライアルと自動更新

  • 無料トライアルは年額プランにのみ付帯し、14日間です。
  • トライアル期間が終了する24時間前までに解約しない場合、自動的に年額プランへ移行し、課金されます。
  • サブスクリプションは、期間終了の24時間前までに自動更新をオフにしない限り、自動的に更新されます。
  • 更新料金は、現在の期間が終了する24時間以内にApple IDアカウントへ請求されます。
  • 購入・更新・解約・無料トライアルの管理は、すべてApp Storeのアカウント設定から行えます。

4. 解約

サブスクリプションはいつでも解約できます。解約は、端末の「設定」→ Apple ID →「サブスクリプション」から行ってください。解約しても、現在の支払い期間の終了までは引き続き全機能をご利用いただけます。期間終了後は閲覧モードとなり、過去の記録・写真の閲覧と書き出しは引き続き可能です。
